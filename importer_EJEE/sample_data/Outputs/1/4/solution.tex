\textbf{Answer: 4)} $\nu \propto \sqrt{\rho G}$

\underline{\textbf{Solution for 4}}

We want to make a frequency, $[\nu] = 1/T$, out of the quantities $[R] = L$, $[\rho] = M/L^3$, and $[G] = L^3/(MT^2)$. These units for $G$ follow from the gravitational force law, $F = Gm_1m_2/r^2$. As in the previous problem, we can play around with these quantities to find the combination that has the correct units, but let's do it the no-fail way. If $\nu \propto R^a \rho^b G^c$, then we have

\begin{equation} \frac{1}{T} = L^a \left(\frac{M}{L^3}\right)^b \left(\frac{L^3}{MT^2}\right)^c. \tag{1.23} \end{equation}

Matching up the powers of the three kinds of units on each side of this equation gives

\begin{equation} M:\ 0 = b-c, \end{equation}
\begin{equation} L:\ 0 = a-3b+3c, \end{equation}
\begin{equation} T:\ -1 = -2c. \tag{1.24} \end{equation}

The solution to this system of equations is $a = 0$, and $b = c = 1/2$. Therefore, our answer is $\nu \propto \sqrt{\rho G}$. So it turns out that there is no $R$ dependence.

\textsc{Remark:} Note the difference in the given quantities in this problem ($R$, $\rho$, and $G$) and the ones in Exercise 1.12 ($R$, $\rho$, and $S$). In this problem with the star, the mass is large enough so that we can ignore the surface tension, $S$. And in Exercise 1.12 with the drop, the mass is small enough so that we can ignore the gravitational force, and hence $G$. $\clubsuit$
