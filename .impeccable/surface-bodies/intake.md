Scope: PDF staging, pair verification, background runs.
Mode: Operate.

Audience/job: archivist stages PDFs, confirms question/solution pairs, runs the extractor, watches jobs.
Proof/content: staged filenames, auto-pair suggestions, live job states, per-paper status.
Constraints: admin only; nothing enters processing until pairs are confirmed; destructive clears need checkbox confirm; no auto-refresh loops (manual Refresh).

Direction: three stacked panels - Stage files / Verify pairs / Pipeline - with Background jobs ledger, queue rows, explicit Run selector, History expander.
Memorable moment: the pair row - question file left, solution select right, one Confirm for all.
