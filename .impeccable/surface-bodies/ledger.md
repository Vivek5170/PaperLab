# Surface brief: Usage Ledger (admin)

Scope: token accounting and cost reporting.
Mode: Read.

Audience/job: archivist answers "what did this cost?" per paper and per phase.
Proof/content: real token summaries, pricing config, currency conversion.
Constraints: admin only; display-only conversion (never writes pricing); student views stay clean.

Direction: 4 metric cells, currency radio (vertical) + rate input, main table, phase-breakdown expander, error warnings, confirm-gated danger zone at bottom.
Memorable moment: the metric row - Total / Extraction / Tagging / Turns in mono.

## Direction contract
THESIS: Cost is a ledger, not a dashboard; numbers first, no chart chrome.
OWN-WORLD: Metric cells with hairline dividers, mono figures, Pine/Ochre confined to deltas.
STORY: Archivist checks totals, drills per-paper and per-phase, manages danger-zone deletes.
FIRST VIEWPORT: H1 Usage Ledger, metric row, pricing caption, main table head.
FORM: metric + table ledger (established, kept and retitled).
SEED REFERENCE: seed: none (unavailable)
